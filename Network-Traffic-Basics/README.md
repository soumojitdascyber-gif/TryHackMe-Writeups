# 🌐 TryHackMe Writeup: Network Traffic Basics

## 📝 Room Overview
* **Room Name:** Network Traffic Basics
* **Platform:** TryHackMe
* **Difficulty:** Easy
* **Category:** Networking / Blue Team

## 🎯 Objective
Learn what network analysis is, why it is essential, how to collect network traffic, and how to identify anomalies like malware and C2 communications.

---

## 💡 Tasks & Answers

### Task: Analyzing Network Traffic
* **Scenario 1:** What is the flag found in the HTTP traffic?
* **Answer:** `THM{FoundTheMalware}`

* **Scenario 2:** What is the flag found in the DNS traffic?
* **Answer:** `THM{C2CommandFound}`

---

## 🧠 Key Learnings
* Understood the fundamentals of network traffic analysis and flow data.
* Successfully identified malicious activities (Malware downloads) over HTTP.
* Detected Command and Control (C2) server communications hidden within DNS traffic.
