# 🌐 TryHackMe Writeup: Learning Cyber Security

## 📝 Room Overview
* **Room Name:** Learning Cyber Security
* **Platform:** TryHackMe
* **Difficulty:** Easy
* **Category:** Fundamentals / General

## 🎯 Objective
Get a short introduction to core security topics, including web application vulnerabilities (like brute-forcing) and the severe real-world financial impacts of network security breaches.

---

## 💡 Tasks & Answers

### Task: Web Application Security
* **Question:** What is the username of the BookFace account you will be taking over?
* **Answer:** `Ben.Spring`
* **Question:** Hack the BookFace account to reveal this task's answer!
* **Answer:** `THM{BRUTEFORCING}`

### Task: Network Security
* **Question:** How much did the data breach cost Target?
* **Answer:** `$300 million`
---

## 🧠 Key Learnings
* **The Cost of Weak Network Security:** A cyber attack isn't just a technical glitch; it's a massive financial disaster. The infamous Target data breach cost the company $300 million, demonstrating why securing network perimeters and tracking user activity is critical for modern businesses
* **Brute-Forcing Web Apps:** If a web application doesn't have rate-limiting (blocking users after too many failed login attempts), attackers can easily guess thousands of passwords against a known username (like `Ben.Spring`) until they successfully take over the account.
