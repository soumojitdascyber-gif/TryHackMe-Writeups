# 🧭 TryHackMe Writeup: Starting Out In Cyber Sec

## 📝 Room Overview
* **Room Name:** Starting Out In Cyber Sec
* **Platform:** TryHackMe
* **Difficulty:** Easy
* **Category:** Fundamentals / Careers

## 🎯 Objective
Understand the primary career paths in Cyber Security, specifically focusing on the differences between Offensive Security (Red Team) and Defensive Security (Blue Team) roles.

---

## 💡 Tasks & Answers

### Task: Offensive Security
* **Question:** What is the name of the career role that is legally employed to find vulnerabilities in applications?
* **Answer:** `penetration tester`

### Task: Defensive Security
* **Question:** What is the name of the role who's job is to identify attacks against an organisation?
* **Answer:** `security analyst`

---

## 🧠 Key Learnings
* **Offensive Security (Penetration Tester):** This role focuses on actively attacking systems. A penetration tester is legally hired by an organization to simulate cyber attacks, uncover vulnerabilities in web applications, networks, and infrastructure, and report them before malicious hackers can exploit them.
* **Defensive Security (Security Analyst):** This role is the shield of the organization. A Security Analyst (often working in a SOC) constantly monitors network traffic, analyzes logs, and investigates alerts to identify, block, and respond to active cyber attacks in real-time.
