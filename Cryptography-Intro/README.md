# 🔐 TryHackMe Writeup: Cryptography Intro (Caesar Cipher)

* **Room Name:** Cryptography (Secret Messages / Caesar Cipher)
* **Platform:** TryHackMe
* **Difficulty:** Easy

## 🎯 Objective
Learn the basics of cryptography, historical encryption methods, and practically apply the Caesar Cipher for encoding and decoding secret messages.

---

## 💡 Tasks & Answers

### Task: Caesar Cipher Decoding
* **Question 1:** What's the flag you received after completing all levels of the Secret Message game?
* **Answer:** `THM{CAESAR_CIPHER_MASTER_2026}`

* **Question 2:** Using the Caesar cipher with a key of 5, what does `CYBER` become?
* **Answer:** `HDGJW`

* **Question 3:** Using the Caesar cipher, find the correct key and decode the following: `SIMPLE CAESAR CIPHER`
* **Answer:** `SIMPLE CAESAR CIPHER`
