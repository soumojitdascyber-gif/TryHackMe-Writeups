Learn how to start and access virtual target machines on TryHackMe, utilize the browser-based AttackBox, and understand fundamental Linux command-line interface (CLI) commands for navigating files and folders.

## 🧠 Key Learnings
* **The AttackBox:** Instead of installing complex hacking software (like Kali Linux) on your own computer, TryHackMe provides an "AttackBox." It is a safe, ready-to-use virtual hacking machine that runs entirely inside your web browser.
* **Basic Linux Navigation:** When you don't have a mouse, you use commands to move around the computer:
  * `ls` (List): Imagine opening a drawer to see what's inside. This command shows you all the files and folders in your current location.
  * `cd` (Change Directory): Imagine walking from the living room into the kitchen. This command moves you into a different folder (e.g., `cd testdir`).
  * `cat` (Concatenate): Imagine picking up a piece of paper and reading it out loud. This command prints the exact contents of a text file directly onto your screen (e.g., `cat hello.txt`).
