# ⚖️ TryHackMe Writeup: The CIA Triad

## 📝 Room Overview
* **Room Name:** The CIA Triad
* **Platform:** TryHackMe
* **Difficulty:** Easy
* **Category:** Security Fundamentals

## 🎯 Objective
Understand the core principles of information security: Confidentiality, Integrity, and Availability (The CIA Triad), and learn how it shapes cyber security mindset.

---

## 💡 Tasks & Answers

### Task: Hands-on Scenario
* **Scenario:** Analyzed nine different security incidents to determine which part of the CIA triad was affected by the attack.
* **Flag Received:** `THM{CIA_IS_ABOUT_BALANCE}`

### Task: Security Mindset
* **Question:** CIA Triad is not just a set of definitions; it's a mindset. What type?
* **Answer:** `Security mindset`

---

## 🧠 Key Learnings
* Understood the importance of balancing Confidentiality, Integrity, and Availability in any system.
* Learned to identify which pillar of the triad is compromised during specific cyber attacks.
