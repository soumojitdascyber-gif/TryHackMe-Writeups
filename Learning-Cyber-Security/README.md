## 🧠 Key Learnings
* **The Cost of Weak Network Security:** A cyber attack isn't just a technical glitch; it's a massive financial disaster. The infamous Target data breach cost the company $300 million, demonstrating why securing network perimeters and tracking user activity is critical for modern businesses[span_11](start_span)[span_11](end_span).
* **Brute-Forcing Web Apps:** If a web application doesn't have rate-limiting (blocking users after too many failed login attempts), attackers can easily guess thousands of passwords against a known username (like `Ben.Spring`) until they successfully take over the account[span_12](start_span)[span_12](end_span).
