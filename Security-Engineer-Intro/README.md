## 🧠 Key Learnings
* **Secure by Design:** Fixing a security vulnerability after a product is launched is incredibly expensive. "Secure by design" means integrating security from the very first day of planning, which provides the best Return on Investment (ROI) for the company.
* **Asset Inventory:** You can't protect what you don't know you have. Maintaining a strict database of every server, IP address, and software owner is the first step in defending a corporate network.
* **Tabletop Exercises:** This is basically a "fire drill" for cyber attacks. The security team, management, and IT staff sit around a table and talk through a simulated scenario (like a massive ransomware attack) to test if their response plans actually work.
* **Business Continuity:** If a massive breach happens, the absolute top priority isn't just catching the hacker—it is ensuring the business can continue operating, serving customers, and making money without complete collapse.
