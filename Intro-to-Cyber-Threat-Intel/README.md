## 🧠 Key Learnings
* **What is CTI?** Cyber Threat Intelligence transforms raw data (like random IP addresses or file hashes) into actionable knowledge[span_12](start_span)[span_12](end_span). It tells you *who* is attacking, *how* they attack, and *why*.
* **The CTI Lifecycle:** Intelligence isn't generated instantly. It starts with the **Direction** phase (asking the right questions)[span_13](start_span)[span_13](end_span), moving through data collection, and then **Processing** (sorting and organizing the raw data into usable formats)[span_14](start_span)[span_14](end_span) before it becomes actual intelligence.
* **TAXII Models:** Threat intelligence needs to be shared securely. TAXII uses two main sharing models: **Collection** (gathering intel) and **Channel** (distributing intel)[span_15](start_span)[span_15](end_span).
