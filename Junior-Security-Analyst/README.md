## 🧠 Key Learnings
* **The SOC (Security Operations Center):** Think of the SOC as the digital security guard room for a company. Analysts sit here to monitor screens, spot bad guys (hackers), and keep the network safe 24/7.
* **Triage & Investigation:** When an alarm (alert) goes off, a junior analyst's first job is to investigate. In this lab, it meant checking a suspicious IP address (`221.181.185.159`) to figure out if it was an actual attack or just a false alarm.
* **Escalation:** You don't have to solve everything alone. If an attack looks too complex or requires higher permissions, the standard protocol is to "escalate" it—meaning you assign the ticket to a Senior Analyst (like Will Griffin) who has more experience.
* **Remediation:** If you confirm an IP address is malicious, you take action to stop it. Blocking that IP on the company firewall is exactly like changing the locks on a door so that specific bad guy can never enter the network again.
