# 🛡️ Defensive Security Intro (TryHackMe)

## 🎯 Objective
Introduce defensive security concepts by investigating an ongoing attack at FakeBank.

## 🧠 Core Concepts & Execution
* **Execution Environment:** Simulated SOC Incident Response Dashboard.
* **Tasks Performed:**
  * Investigated malicious activity and locked the compromised user account `dave.saunders`.
  * Updated FakeBank's threat intelligence systems with attack details regarding the targeted page and username (`ShadowFigures`).
  * Submitted incident report identified as `SEC-2026-341`.

## 🚩 Proof of Compromise
* **Flag(s) Found:** 
  * `THM{ACCOUNT-LOCKED}`
  * `THM{INTEL-UPDATED}`

## 💡 Security Takeaway
Immediate threat containment (like locking compromised accounts) and accurate incident documentation are crucial for stopping active intrusions and preserving evidence.
